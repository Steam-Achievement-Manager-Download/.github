## About

**Steam Achievement Manager (SAM)** is a community-developed utility designed for managing Steam achievements on supported games. It provides a convenient interface for viewing a game's achievement list and changing the unlocked status of individual achievements.

Instead of navigating through multiple menus, users can select a game from their Steam library and access its available achievements in one place.

SAM is commonly used by players who want to manage achievement states, review achievement lists, or experiment with how achievements appear on their Steam profiles.

> **Simple and straightforward:** select a game, review its achievements, and use the available controls to manage their status.

## Features

### Steam Game Integration

Detects supported games associated with your Steam account and allows you to select a title for achievement management.

### Achievement Status Management

Provides controls for changing the unlocked status of individual achievements supported by the selected game.

### Convenient Game Selection

Browse available game entries and access their achievement lists through a straightforward interface.

### Achievement Overview

View achievement names and related information made available by the selected game's Steam achievement data.

### Lightweight Utility

Offers a focused interface for achievement management without requiring a separate launcher or a complex setup process.

## Troubleshooting Guide

If SAM does not display your games or achievements correctly, check the following common issues.

### No Games Are Displayed

Make sure Steam is installed and running, and that you are signed in to the correct account. Verify that the games are associated with that account.

### Achievements Are Missing

Some games may not expose achievement information in the expected way. Check that the selected title supports Steam achievements and that its achievement data is available.

### The Application Does Not Start

Extract all files from the downloaded archive before launching the program. Check the release notes and verify that the version is compatible with your Windows environment.

### Changes Do Not Appear in Steam

Achievement updates may depend on the game's implementation and Steam's handling of achievement data. Restart Steam and check the game's achievement page again. Avoid repeatedly applying changes if the result is unclear.

### Security Warning Appears

Download SAM only from the project's repository or another source you independently trust. Review security warnings carefully before deciding whether to run an executable.
